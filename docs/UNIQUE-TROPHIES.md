# Unique trophy additions

Eight new goals appear in the existing Trophies section, each with distinct SVG artwork and a once-only coin/diamond reward. No new numbered win milestones, login/win streak chains, or copied existing trophy goals are added. Existing trophies (including legacy overlapping goals) and earned IDs remain unchanged.

| Trophy | Goal | Coins / diamonds |
| --- | --- | --- |
| Three Arts of the Tree | 5 hits in each of the three Tree Pot modes | 120 / 2 |
| Precision Spark | Complete Lightning Hands at 100% accuracy | 100 / 2 |
| Mind Palace | Finish Three-Hand Memory through length six | 90 / 2 |
| Uncopied Shadow | Paid Shadow win without repeating a hand | 110 / 2 |
| Eight Disciplines | Complete all eight currently playable academy games | 200 / 4 |
| Balanced Toolkit | Buy a level of Coin Purse and Scholar’s Scroll | 80 / 1 |
| Finishing Touch | Equip an owned paid finisher, gi, band and aura together | 80 / 1 |
| A Light Restored | Rescue first dojo | 100 / 2 |

Existing saved bests/clears, rescue and equipment data can qualify retroactively on login or a successful action. Uncopied Shadow needs a qualifying saved winning run or a new qualifying win because old aggregate clear counts cannot prove hand variety. No old history is fabricated. All successful action paths check trophy entitlement; repeated events, reloads and already-earned IDs do not repay. Invalid/no-op actions keep identity and cannot award. Saves remain version 4 with the existing trophy ID list; no destructive migration.
